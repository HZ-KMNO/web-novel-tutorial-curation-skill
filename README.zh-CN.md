# 网文教程整理 Skill

![网文教程整理徽标](assets/logo.png)

这是一个面向 AI agents 的通用 skill，用于把网文/小说写作教程、平台文章、作者访谈、课程资料、本地电子书、优秀小说案例库或混合文档整理成可复用的 AI 知识库。

它不是“写小说正文”的 skill，而是“把写作教程与优秀作品案例整理成 AI 能长期调用的资料源”的 skill。

## 这个 Skill 解决什么问题

AI 在处理教程资料时，很容易出现这些问题：

- 只看网页表面内容，没有检查接口、服务端 HTML 或脚本数据；
- 没先提取列表就直接抓详情，导致数量和范围不准；
- 默认所有详情页模板相同，遇到图解、视频、旧模板、跳转页就误判失败；
- 把教程全文复制到本地，既占空间，也不适合后续 AI 调用；
- 把优秀小说案例当成普通教程处理，只写剧情梗概，不提炼可迁移的写作机制；
- 标签规则太宽，导致大量文章被错误归到同一个主题；
- JSON 没校验，Markdown 表格被竖线破坏，中文文件编码乱码；
- 提取资料后忘了同步到主说明、注入 prompt 或已有 skill；
- 通用 prompt 里残留具体项目内容，让其他 AI 误用。

这个 skill 把这些经验固化成流程、模板和质量门槛，帮助其他 AI 更高效、更稳定地完成类似任务。

## 适用场景

当用户要求 AI 做以下事情时，适合使用本 skill：

- 提取某个写作教程网站前 N 页文章；
- 整理平台作家课堂、网文教程、作者专访、签约指南；
- 阅读本地写作教程文件夹并生成摘要库；
- 阅读优秀小说、经典作品、标杆网文或 EPUB 小说案例库，并提炼开篇承诺、冲突系统、人物压力、悬念控制、结构节奏、风格和结尾回收；
- 把教程资料分类成“开篇、大纲、人物、冲突、节奏、签约、投稿、平台规则、版权、去 AI 味”等主题；
- 生成 Markdown 总结和 JSON 索引；
- 把新资料源同步到主 AI 的说明文件、注入 prompt 或 skill；
- 检查提取结果是否完整、可靠、可被后续 AI 使用。

## 推荐输出结构

中文项目建议输出：

```text
教程库/
├─ 00_总览与使用说明.md
├─ 01_全部文章.md
├─ 02_栏目分类总结.md
├─ 03_主题索引.md
└─ 教程_文章索引.json
```

其中：

- `00_总览与使用说明.md`：给人和 AI 快速理解资料源、数量、用途和调用顺序。
- `01_全部文章.md`：完整文章索引，按页码、排名或原始顺序排列。
- `02_栏目分类总结.md`：按原网站栏目、课程分类、文件夹分类聚合。
- `03_主题索引.md`：按写作任务主题聚合，方便 AI 写稿或修稿时快速选资料。
- `教程_文章索引.json`：结构化索引，方便脚本、AI 或检索工具调用。

如果资料源是优秀小说案例库，建议输出：

```text
案例库/
├─ 00_总览.md
├─ 01_案例索引.md
├─ 02_写作技法模式.md
├─ 03_AI调用地图.md
└─ 案例索引.json
```

案例库的重点不是复述剧情，而是记录“这部作品能教 AI 什么”：例如开篇承诺、主角压力、冲突系统、信息差、人物网、母题、场景经济性、语言风格、结尾回收，以及哪些地方不能直接模仿。

## 每条资料建议保留的字段

```text
来源名称
来源 URL
提取日期
页码/排名/顺序
文章 ID
标题
栏目/分类
日期
阅读/点赞/收藏等统计
原文链接
正文状态
标签
摘要
可借用经验
限制说明
```

正文状态很重要，例如：

- `standard_text`：标准正文页；
- `low_text`：页面文字较少；
- `image_only`：图解或图片型内容；
- `video_only`：视频型内容；
- `template_changed`：旧模板或不同模板；
- `blocked_or_login_required`：受限或需要登录。

这样后续 AI 不会把“没有抓到正文”误当成“文章不存在”。

## 核心流程

1. **确认范围**
   - URL、文件夹、页数、筛选条件、排序方式、输出目录。

2. **发现数据来源**
   - 看网页是否是服务端 HTML、前端渲染、接口 JSON、脚本注入数据或混合结构。

3. **先抓列表**
   - 先得到所有文章标题、链接、栏目、日期、摘要和统计。
   - 先校验数量，再抓详情。

4. **再抓详情**
   - 处理正文页、图解页、视频页、旧模板、跳转页。
   - 对非标准页面标注状态，不要直接丢弃。

5. **摘要化而不是搬运**
   - 不默认保存完整原文。
   - 把教程转化为写作原则、检查项、适用阶段和可执行经验。
   - 如果是优秀小说案例，只保存元数据、技法分析、可迁移经验和模仿风险，不复制正文或章节。

6. **双层分类**
   - 按原网站栏目分类；
   - 按 AI 写作任务主题分类。

7. **验证**
   - 数量、重复、JSON、Markdown、编码、链接、标签质量、低文本页数量。

8. **同步到主文件**
   - 更新资料源清单、注入 prompt、已有 skill、主说明文件。
   - 删除或修正过时、错误、项目专属残留内容。

## 质量门槛

完成前至少检查：

- 是否记录了源 URL、页数、筛选条件和提取日期；
- 是否知道总数、分类数、低文本页数量；
- JSON 是否能解析；
- Markdown 表格是否被 `|` 破坏；
- 中文文件是否符合项目编码习惯；
- 标签是否过宽；
- 是否没有保存完整版权原文；
- 是否同步到主 prompt / skill / 总说明；
- 如果是优秀小说案例，是否明确区分为“案例库”而不是“教程库”；
- 是否没有把案例分析写成单纯剧情梗概；
- 通用 skill 或 prompt 是否不包含具体项目剧情；
- skill 是否能通过对应验证脚本。

## 安装方式

把这个文件夹复制到你的 AI agent skill 目录：

```text
web-novel-tutorial-curation/
```

核心文件是：

```text
web-novel-tutorial-curation/SKILL.md
```

如果你的 AI 系统支持 OpenAI/Codex 风格 skill，会读取 `SKILL.md` 的 frontmatter 来判断何时触发。

## 示例提示词

```text
使用 $web-novel-tutorial-curation，提取这个写作教程网站前 30 页所有文章，生成 Markdown 和 JSON 摘要库，校验数量、链接和标签质量，并把新资料源同步到我的小说写作主说明与注入 prompt。
```

```text
使用 $web-novel-tutorial-curation，总结这个优秀小说 EPUB 文件夹，把它整理成案例库：先建立元数据索引，再按写作技法分类，提炼可迁移经验，标明不能直接模仿的风险，并同步到我的 AI 写作资料源说明。
```
